# Toolify

Kumpulan alat online yang memproses file di browser: kompres gambar, generator QR code, dan konversi gambar ke PDF.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite. Untuk membuat versi produksi, jalankan `npm run build`; hasilnya tersedia di folder `dist/`.
